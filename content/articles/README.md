# Контент 007fin

Здесь хранятся исходники статей для журнала 007fin. Один каталог соответствует одной публикации.

Пример:

```text
content/articles/001-mfo-or-bank/
  article.md
  meta.json
  cover.webp
```

## Правила

- `article.md` содержит отдельный оригинальный текст статьи.
- `meta.json` хранит slug, заголовок, описание, тему, автора и статус.
- `cover.webp` необязателен до подготовки изображения, но перед публикацией страницы нужен согласованный файл.
- Одна статья не копируется дословно на внешнюю площадку и на 007fin.
- В каждой публикации заранее фиксируется одна целевая ссылка и источник фактов.
- Реальные ставки, выплаты и условия партнёрских сетей не добавляются без подтверждения из кабинета или официальной документации.
- Персональные данные, токены и содержимое `.env` в этот каталог не помещаются.

## Статусы

`draft` - тема выбрана, текст не готов.

`review` - текст готов и ждёт фактологической, юридической и SEO-проверки.

`ready` - проверен текст, ссылка, изображение и метаданные.

`published` - страница размещена на 007fin и проверена в браузере.

Внешнее размещение получает отдельный статус и не считается опубликованным только потому, что статья есть на 007fin.
